## 🎯 WHAT YOU CAN DO RIGHT NOW

### As Mentor:

1. **Login** to https://www.zentrixlearnit.in
2. **Create a Class**:
   - Go to Classes tab
   - Click "Create New Class"
   - Fill in details
   - Save

3. **Create an Assignment**:
   - Go to Assignments tab
   - Click "Create Assignment"
   - Select class, set deadline
   - Save

4. **Create an Assessment**:
   - Go to Assessments tab
   - Click "Create Assessment"
   - Fill form (title, class, marks, duration)
   - Schedule assessment

5. **Mark Attendance**:
   - Go to Attendance tab
   - Click "Mark Manually"
   - Select students
   - Mark Present/Absent/Late
   - Save

6. **Upload Materials**:
   - Go to Materials tab
   - Click "Upload New"
   - Select file and type
   - Upload

7. **Create Announcement**:
   - Go to Announcements tab
   - Click "Create"
   - Write message
   - Publish

### As Student:

1. **Login** to https://www.zentrixlearnit.in
2. **View Dashboard**:
   - See all your stats
   - View upcoming assignments
   - Check attendance rate

3. **Submit Assignment**:
   - Go to Assignments tab
   - Click on pending assignment
   - Upload your work
   - Submit

4. **Take Assessment**:
   - Go to Assessments tab
   - Click "Start Assessment"
   - Answer questions
   - Submit

5. **View Materials**:
   - Go to Materials tab
   - Browse and download

6. **Check Attendance**:
   - Go to Attendance tab
   - See your attendance history
